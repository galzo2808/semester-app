# הסמסטר שלי

אפליקציה לניהול הסמסטר והתואר. סטודנטים בנו אותה לעצמם, והיא אינה אפליקציה רשמית של רופין.
התוכנית המלאה נמצאת ב־[docs/PLAN.md](docs/PLAN.md).

## הרצה
דרוש Node.js 20 ומעלה.

```bash
npm install
npm run dev      # שרת פיתוח: http://localhost:5173
npm test         # בדיקות
npm run build    # בנייה לפרסום (תיקיית dist)
```

## מבנה
- `src/domain` – טיפוסים וכללים טהורים, כמו תאריכים, שבועות בסמסטר ולוח שנה. לכל קובץ יש בדיקות.
- `src/data` – מסד הנתונים (IndexedDB דרך Dexie), נתוני פתיחה ופונקציות קריאה וכתיבה. המסכים ניגשים לנתונים רק דרכן.
- `src/i18n/he.ts` – כל הטקסטים, כולל צורת זכר ונקבה.
- `src/ui` – עיצוב (`theme.css`, כל הצבעים במקום אחד) ורכיבים משותפים.
- `src/features/*` – מסך לכל פיצ׳ר, ולכל אחד README קצר.

## התקנה בטלפון
1. פותחים את קישור האפליקציה ב־Safari באייפון (או ב־Chrome באנדרואיד).
2. לוחצים על כפתור השיתוף ובוחרים "הוספה למסך הבית".
3. האפליקציה נפתחת במסך מלא ועובדת גם בלי אינטרנט. כשיוצאת גרסה חדשה מופיעה הודעה "עדכון", והנתונים נשמרים.

## פרסום (GitHub Pages, חינם)
הקובץ `.github/workflows/deploy.yml` בונה ומפרסם את האפליקציה בכל דחיפה לענף `main`.
פעם אחת: יוצרים מאגר ב־GitHub, דוחפים אליו את הקוד, ובהגדרות המאגר בוחרים Pages → Source: GitHub Actions.
הקישור לשיתוף: `https://<שם-המשתמש>.github.io/<שם-המאגר>/`.
