# מבחנים
- רשימת המבחנים לפי תאריך מועד א׳, עם ספירה לאחור בימים. מועד ב׳ מוצג מתחת לכל קורס.
- "מבחנים נוספים": אירועי לוח שנה מסוג `exam` (למשל הקורס המקוון למניעת הטרדה מינית).
- `ExamPeriodCard` (גם במסך היום): ימים עד תקופת הבחינות והמבחן הבא.
- שעות וכיתות עוד לא פורסמו. בשלב 6 תתווסף עריכה ותכנון למידה אוטומטי.
