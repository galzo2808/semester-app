# לוח שבועי ומערכת שעות
- **שבוע:** ראשון עד שישי, עם מעבר בין שבועות. בכל יום: השיעורים לפי הסדר (שעה, קורס, סוג, כיתה), חגים, וסימון "יום לימודים".
- **מסך היום:** כרטיס "השיעורים של היום" (`LessonList`).
- **מערכת השעות היא בסיס:** כפתור "סימון ביטול" מבטל שיעור לתאריך אחד בלבד, ולחיצה נוספת מחזירה אותו. שיעור נוסף (השלמה) מופיע עם תג "שיעור נוסף" ואפשר להסיר אותו.
- הכללים ב־`domain/schedule.ts` (`lessonsOn`): שיעורים קבועים לפי יום בשבוע, בתוך הסמסטר, בלי חגים, ועם שינויים חד־פעמיים (`LessonChange`).
- הנתונים ההתחלתיים: `data/seed/schedule5787a.ts`.
