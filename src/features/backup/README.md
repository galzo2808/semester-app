# גיבוי ושחזור
- **יצירת קובץ גיבוי** (מסך "עוד"): כל הנתונים במכשיר, כולל קבצי סיכום, בקובץ JSON אחד. בטלפון נפתח חלון השיתוף (שמירה ב"קבצים", בדרייב או בוואטסאפ); במחשב הקובץ יורד.
- **שחזור מקובץ:** בודק שהקובץ תקין, מבקש אישור ומחליף את כל הנתונים במכשיר. השחזור קורה בפעולה אחת: אם משהו נכשל, שום דבר לא משתנה.
- **תזכורת** במסך היום: אחרי 14 יום בלי גיבוי, או כשיש התקדמות ועוד לא נעשה גיבוי בכלל. התקנה חדשה בלי נתונים לא מקבלת תזכורת.
- הקוד: `data/backup.ts` (יצירה, בדיקה, שחזור), `domain/backup.ts` (מתי להזכיר).
- הקובץ כולל את גרסת מבנה הנתונים, כך שאפשר לשחזר גיבוי ישן גם בגרסה חדשה של האפליקציה.
