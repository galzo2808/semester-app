# יומן קריאה
לשונית "קריאה" בדף הקורס: ספרים ומאמרים בנפרד. לכל פריט: מחבר וכותרת, פרקים/עמודים, שבוע בסילבוס (או טווח שבועות), חובה/רשות, הערה, קישור.
לחיצה על הסטטוס מקדמת אותו: לא התחלתי → בקריאה → נקרא → יש סיכום.
`ReadingRow` משמש גם בכרטיס "קריאה לשבוע" במסך היום. הכללים ב־`domain/reading.ts`.
העלאת קבצי סיכום לכל פריט תתווסף בשלב 5.
