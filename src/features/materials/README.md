# חומרים
לשונית "חומרים" בדף הקורס: קישורים לסיכומים ותיקיות בדרייב, מקובצים לפי סוג (לקראת המבחן, סיכומי קריאה, סיכומי שיעורים, תרגול, תיקיות).
הקבצים עצמם לא מועתקים לאפליקציה: נשמר רק קישור, עם ציון המקור (קרדיט).
קישורים בלי קורס (`courseId` ריק) מוצגים במסך "עוד" תחת "קישורים שימושיים".
הנתונים ההתחלתיים: `data/seed/syllabus5787a.ts`.
